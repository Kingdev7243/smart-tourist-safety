Smart Tourist Safety — Admin Command Center
The Admin Command Center is the administrative frontend for the Smart Tourist Safety Monitoring System.

It provides authorized administrators and safety operators with a centralized interface for monitoring tourists, incidents, alerts, trips, and safety zones through the project's backend API.

Overview
The Admin Command Center is designed for use by:

Super Administrators
Safety Operators
Inspectors
It connects directly to the Smart Tourist Safety backend and uses the backend's authentication, authorization, and database APIs.

The frontend does not use mock data for its core application functionality.

Features
Authentication
Admin login through the backend authentication API
JWT-based authentication
Protected administrative actions
Role-based access control
Automatic handling of expired or invalid sessions
Supported roles:

SUPER_ADMIN
OPERATOR
INSPECTOR
Dashboard
Provides an overview of the current safety situation, including:

Active incidents
Emergency alerts
Safety zones
Tourist information
System status
Incident Monitoring
Administrators can:

View reported incidents
Inspect incident details
Monitor incident severity and status
Update incident status
Resolve incidents when authorized
Incident creation remains available through the backend for the tourist/client application.

Emergency Alerts
Administrators can:

View active alerts
Inspect alert information
Acknowledge alerts
Update alert status when authorized
Alerts are intended to be generated by the backend safety system rather than manually created by administrators.

Safety Zones
Authorized administrators can:

View safety zones
Create safety zones
Modify existing zones
View zone risk levels
Monitor zone locations
Manage active/inactive zones
Safety zones are backed by the backend database and are intended to support the system's future geofencing functionality.

Interactive Safety Map
The command center includes an interactive map interface for visualizing:

Safety zones
Incident locations
Geographic coordinates
Risk information
The map is designed to help administrators understand the geographic relationship between incidents and safety zones.

Tourist & Trip Monitoring
The frontend provides administrative views for:

Registered tourists
Tourist contact information
Tourist trips
Trip destinations
Trip status
These views retrieve information from the backend API rather than maintaining a separate frontend database.

Multilingual Interface
The Admin Command Center supports:

English
Tamil (தமிழ்)
Hindi (हिन्दी)
The language can be changed from within the application.

Technology
The frontend is built using:

React
TypeScript
Vite
Tailwind CSS
JWT authentication
REST API integration
The application communicates with the Smart Tourist Safety backend through HTTP API endpoints.
